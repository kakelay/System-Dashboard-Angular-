# Enterprise Back-Office Web Application

A professional-grade Angular 16 administration portal featuring a modular architecture, lazy loading, and comprehensive security.

## Features

- **Enterprise Architecture**: Core/Shared/Feature module structure.
- **Security**: JWT-based mock authentication, AuthGuard, and RoleGuard.
- **Lazy Loading**: All features load on-demand for optimized performance.
- **Responsive Layout**: Collapsible sidebar, sticky navbar, and flexible content area.
- **Reusable Components**: Generic Data-Table component with dynamic columns.
- **Feature Modules**:
    - Dashboard with KPI statistics.
    - User & Role Management (Admin only).
    - Customer CRM listing.
    - Transaction monitoring with filters.
    - Reporting suite.
    - System Audit Log.
    - Application Settings.

## Tech Stack

- **Framework**: Angular 16
- **Styling**: SCSS (Variables, Flexbox, Grid)
- **State Management**: RxJS (BehaviorSubjects)
- **Forms**: Angular Reactive Forms
- **Icons**: Material Design Icons
